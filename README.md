## 🚀 Quick Start

### 1. Development Mode
```bash
npm install
npm run dev
```

### 2. Production Build & Preview
```bash
npm run build
npm run preview
```
Visit `http://localhost:5173/` in your browser.

## 🛠️ Core Stack & Architecture

- **Frontend Engine**: React 19 + TypeScript + Vite 8
- **Styling**: Tailwind CSS v4 + Custom Cyberpunk Glows & Animations
- **3D Graphics**: Three.js (Procedural Catmull-Rom Spine, Articulated Vertebrae, Additive Particle System)
- **Interactive Particles**: HTML5 2D Canvas Particle Emitter with fluid physics & constellation linking
- **Smooth Scroll**: Lenis Momentum Inertial Scroll Engine + GSAP
- **Sound Design**: Native Web Audio API procedural audio synthesis
- **Icons**: Lucide React
- **Typography**: `Syne`, `Space Grotesk`, `JetBrains Mono` via Google Fonts
